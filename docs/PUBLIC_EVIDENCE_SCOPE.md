# Evidence scope

The [identity summary](../evidence/FINAL_IDENTITY_PUBLIC.json) records the owner-confirmed actual submission ZIP and the checked official team result. A per-submission platform receipt or submission ID has not been archived.

The [source-check summary](../evidence/PUBLIC_REBUILD_CHECKS.json) records the two fresh-environment input cases, their original component labels, input/output hashes, and official output-gate results. It is a sanitized summary, not the complete raw execution log.

Earlier compatibility summaries, retrospective proxy comparisons, and source-path audits are retained under [provenance](../provenance/README.md). Historical labels are preserved there so the records remain interpretable. They are not instructions to run additional methods, nor substitutes for the official Final result.

No team claim/proof, private receipt, task input, or raw private log is included. File hashes in [the source map](../provenance/SOURCE_MAP.json) identify the published files and distinguish them from their original sources.
